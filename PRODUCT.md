# Product

## Register

product

## Platform

web

## Users

Developers and technical teams deploying, operating, and troubleshooting applications on Liara. They usually arrive while implementing a deployment or diagnosing a production issue and need a reliable answer quickly, without searching several documentation pages or opening a support ticket.

## Product Purpose

Liara Copilot turns Liara documentation into grounded, actionable help. It recognizes whether the user is asking, debugging, or building; retrieves relevant evidence; answers with citations; preserves conversational context; and offers a useful next action. Success means fewer support dependencies and a shorter path from question to resolved problem.

## Positioning

An evidence-first developer copilot for Liara—not a generic chatbot with retrieval attached.

## Brand Personality

Calm, exact, and capable. The voice is concise and collaborative: technically confident when evidence is strong, explicit about uncertainty when it is not, and focused on helping the user complete the next concrete step.

## Anti-references

Avoid a heavy dashboard, decorative AI theatrics, glassmorphism, noisy gradients, novelty chat bubbles, and UI that hides sources or tool activity. The product must not imply certainty without documentation evidence.

## Design Principles

- Evidence is visible, not buried.
- The conversation remains the primary workspace.
- Complexity appears progressively only when the task needs it.
- Every response should move the user toward a verifiable next step.
- Familiar developer-tool patterns take priority over decorative novelty.

## Accessibility & Inclusion

The interface supports keyboard navigation, visible focus states, semantic controls, reduced motion, high-contrast text, screen-reader announcements for streamed responses, and responsive use from mobile through desktop. Persian content uses right-to-left layout while code and commands remain left-to-right.
